% Abstract
\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Tuberculosis (TB), COVID-19, and pneumonia are still major causes of illness and death worldwide. Chest X-rays are usually the easiest imaging test to get for first screening, but many regions have too few radiologists to read them. Deep learning can help with screening, yet most student and demo systems train a separate model for each disease, each on its own label set. That makes it impossible to compare architectures fairly, and a single uploaded image cannot get one answer covering all diseases. Reported accuracy is also often inflated by data leakage (the same patient or duplicate files in both training and test sets) and by preprocessing that differs between training and deployment.

We built an \textbf{AI Agent for Lung Disease Detection}, a chest X-ray system that sorts each image into one of four fixed classes: Normal, Tuberculosis, COVID-19, or Pneumonia. We trained three architectures on one shared manifest merged from three public datasets: EfficientNetB3 and DenseNet121, both fine-tuned from ImageNet, and a custom CNN trained from scratch. To keep the comparison fair, we removed duplicate images by content hash, split the data by patient, drew Normal and Pneumonia images from more than one source, capped class sizes and added inverse-frequency class weights, gave both transfer models the same classification head, and unfroze roughly the same share of each backbone (about 43\%) during fine-tuning. We report per-class precision, recall, and F1-score, balanced accuracy, confusion matrices, and soft-voting ensemble metrics, and we ran a source-leakage probe, because overall accuracy alone hides how the minority class performs.

A Flask web application runs every available four-class model on each upload. It first checks that the image looks like a chest X-ray (the user can override this with ``Analyse anyway''), then shows each model's class probabilities, the ensemble verdict, and whether the models agree. Training and inference use the same bilinear resize. On the held-out test split ($n=482$), DenseNet121 reached 90.87\% accuracy and 89.14\% balanced accuracy, and the soft-voting ensemble reached 92.32\% accuracy and 93.07\% balanced accuracy. COVID-19, the smallest class, had high recall but low precision. The source-leakage probe identified the source dataset with 88.17\% accuracy against a 49.79\% majority baseline, which indicates a moderate source signal. The system is a research demonstration built on public data and is \textbf{not} a clinical diagnostic device.
