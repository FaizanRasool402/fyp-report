\chaptertitlepage{Results and Discussion}

This chapter reports measured results for the unified four-class system on the held-out test split of \path{training/manifest.csv}. All Accuracy, Precision, Recall, F1, confusion-matrix, and leakage-probe figures below are taken from verified evaluation exports (\path{training/results/comparison.md}, \path{results.json}, \path{ensemble.json}, \path{leakage_probe.json}, and run logs). Historical single-disease scores remain labelled as prior work and are not mixed into the four-class tables.

\section{Experimental Setup}

Evaluation used seed 1337, patient-grouped splits, and class order Normal, Tuberculosis, COVID-19, Pneumonia. The realised split sizes were 2{,}260 / 485 / 482 images (70.0\% / 15.0\% / 14.9\%). Models were trained with batch size 32 and inverse-frequency class weights (COVID-19 weight $\approx$ 2.851). The per-class selection cap used for this run was 1{,}200 (\texttt{--cap 1200}).

\section{Leakage Probe}
\label{sec:leakage}

A source-prediction probe (custom CNN @ $150\times150$, 8 epochs) scored \textbf{88.17\%} source accuracy against a majority-class baseline of \textbf{49.79\%} (+38.4 percentage points). The recorded verdict is \textbf{moderate}: datasets are partly separable by source, but not trivially near 100\%. Because Tuberculosis and COVID-19 are single-source, part of their recall could rest on scanner/processing cues; Normal and Pneumonia are multi-source and less exposed to that shortcut. This caveat should be read alongside the disease-classification tables.

\section{Summary of Findings}

On the unified four-class test set ($n=482$), DenseNet121 is the strongest single backbone (90.87\% accuracy; 89.14\% balanced accuracy; macro F1 0.864), while soft-voting ensemble reaches 92.32\% accuracy and 93.07\% balanced accuracy. Pneumonia recall is high across models ($\ge$95\%). COVID-19 remains the difficult minority class: recall can be high (ensemble 94.7\%) while precision stays modest, reflecting only 19 COVID test images. The leakage probe shows moderate source signal (88.17\% vs 49.79\% baseline), so single-source TB/COVID results should be interpreted cautiously. The redesign met its goal: the three architectures were compared fairly on shared data, and the per-class metrics show how the minority class performs, which overall accuracy would have hidden.
