\chaptertitlepage{Results and Discussion}

This chapter gives the measured results of the four-class system on the held-out test set from \path{training/manifest.csv}. All accuracy, precision, recall, F1, confusion matrix and leakage probe numbers below come from the checked evaluation files (\path{training/results/comparison.md}, \path{results.json}, \path{ensemble.json}, \path{leakage_probe.json} and the run logs). Older single-disease scores are marked as prior work and are kept out of the four-class tables.

\section{Experimental Setup}

We used seed 1337, splits grouped by patient, and the class order Normal, Tuberculosis, COVID-19, Pneumonia. The final splits had 2{,}260, 485 and 482 images (70.0\%, 15.0\% and 14.9\%). The models were trained with a batch size of 32 and with class weights based on how rare each class is (COVID-19 weight $\approx$ 2.851). In this run, each class was limited to at most 1{,}200 images (\texttt{-{}-cap 1200}).

\section{Leakage Probe}
\label{sec:leakage}

We trained a probe (a custom CNN at $150\times150$, for 8 epochs) to guess which dataset each image came from. It was right \textbf{88.17\%} of the time, compared with a majority-class baseline of \textbf{49.79\%}, which is 38.4 percentage points higher. We rate this as \textbf{moderate}: the datasets can partly be told apart by source, but not easily or close to 100\%. Since Tuberculosis and COVID-19 each come from one source, part of their recall may come from scanner or processing differences. Normal and Pneumonia come from several sources, so they are less affected. Keep this in mind when reading the disease classification tables.

\section{Summary of Findings}

On the four-class test set ($n=482$), DenseNet121 is the best single model (90.87\% accuracy, 89.14\% balanced accuracy, macro F1 0.864), and the soft-voting ensemble reaches 92.32\% accuracy and 93.07\% balanced accuracy. All models find pneumonia well, with recall of 95\% or more. COVID-19 is still the hard class: recall can be high (94.7\% for the ensemble) but precision stays modest, because there are only 19 COVID test images. The leakage probe shows a moderate source signal (88.17\% against a 49.79\% baseline), so the TB and COVID results, which each come from one source, should be read with care. Overall, the results meet the goal of the redesign: a fair comparison of several models on the same data, with metrics that show how the small classes perform instead of hiding them behind a single accuracy number.
