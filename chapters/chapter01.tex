\chaptertitlepage{Introduction}

\section{Motivation}

Lung diseases are still one of the biggest health problems in the world. According to the World Health Organization, lower respiratory infections are among the top ten causes of death, and tuberculosis alone kills more than 1.5 million people every year~\cite{who2023}. Pneumonia, COVID-19 and other respiratory infections affect people of all ages, but young children (under five) and older people are at the highest risk of serious illness. These diseases also cost a lot in hospital care, lost work and late treatment. The burden is heaviest in low- and middle-income countries, where testing facilities are weakest.

A chest X-ray is usually the cheapest and most easily available scan for checking the lungs. It can be taken quickly, even at the bedside with a portable machine, and it often shows typical signs such as consolidation, cavities or ground-glass opacity. The problem is that someone still has to read the image, and trained radiologists are not available everywhere. In many rural and high-burden areas, X-rays wait a long time before anyone reports on them. This delays triage, isolation and treatment for TB, COVID-19 and pneumonia.

Deep learning has done well on clearly defined chest X-ray screening tasks, especially convolutional neural networks (CNNs) that start from ImageNet weights~\cite{deng2009}. A CNN learns useful image features on its own, without hand-made descriptors, and can flag suspicious cases so they are looked at first. Still, many student and demo systems train a separate model for each disease, each with its own labels. With that setup the models cannot be compared fairly, and the user has to guess the disease before uploading an image. Decisions such as which model to deploy, how to check uploads and how to report results for small classes should be based on evidence, not guesswork.

For these reasons, this project uses one shared workflow. There is one set of four labels, three models trained under the same conditions, clear metrics (including recall for each class and a leakage probe), and a single web app that shows the opinion of every model along with a combined verdict. The aim is not to replace radiologists. The aim is a research demo of multi-disease chest X-ray classification that can be repeated, is evaluated honestly, and handles uploads more safely.

\section{Problem Statement}

Many demo systems train separate models for separate diseases, each with different labels. Because of this, the models cannot be compared fairly, and one uploaded image cannot get a single, consistent answer across all diseases. Reported accuracy is also often too optimistic because of data leakage (the same patient or the same file in both training and test data) or because images are processed differently during training and in the app. On top of this, weak input checks can let images that are not X-rays reach the model.

\textbf{Problem:} Design and build a repeatable system that uses several models to classify chest X-rays as Normal, Tuberculosis, COVID-19 or Pneumonia. All models should use the same data and splits, report clear metrics, and be available through an easy web interface that checks the input and combines the model outputs.

\begin{itemize}
    \item There are not enough radiologists, and their workload delays the reading of chest X-rays in many places.
    \item Single-disease models trained on separate datasets cannot be compared, and they split the user's work across different tools.
    \item A proper research solution has to prevent leakage, process images the same way in training and in the app, and report results for small classes honestly, especially COVID-19, which has very few images.
\end{itemize}

\section{Aim and Objectives}

\textbf{Aim:}
\begin{itemize}
    \item To build a research chest X-ray system that compares three deep learning models on one shared four-class dataset and makes them available through a web app that can combine their results.
\end{itemize}

\textbf{Objectives:}
\begin{enumerate}
    \item Combine three public chest X-ray datasets into one 4-class list (manifest), remove duplicate images, and split the data by patient.
    \item Build EfficientNetB3, DenseNet121 and a custom CNN, train them in the same way, and give the two transfer models the same classification head.
    \item Train and test the models using precision, recall and F1 for each class, balanced accuracy, confusion matrices and a source-leakage probe.
    \item Build a Flask app that runs every model on each upload, combines them with soft voting, and checks in several stages that the upload is a chest X-ray.
    \item Document the method, its limitations and how to repeat it (manifest, seeds and scripts).
\end{enumerate}
