\label{app:datasets}

\section{Dataset Overview}

The combined dataset has four classes, and each image belongs to exactly one of them: Normal, Tuberculosis, COVID-19 or Pneumonia. In the reported run, COVID-19 has 130 images after removing duplicates. Normal and Pneumonia are limited to 1{,}200 images each, and class weights based on class size are used during training.

\chaptertitlepage{Model Architecture Summaries}
\label{app:architectures}

\section{Model Training and Implementation}

\begin{itemize}
    \item EfficientNetB3 / DenseNet121: ImageNet base plus shared head (GAP, Dropout, Dense 256, Dropout, Softmax 4); Phase~1 frozen; Phase~2 unfreeze from layers 340 / 300 ($\sim$43\%).
    \item Custom CNN: five convolution blocks ending in Softmax(4).
    \item Scripts: \path{training/build_manifest.py}, \path{common.py}, \path{models.py}, \path{train.py}, \path{evaluate.py}, \path{leakage_probe.py}; frontend under \path{Frontend/}; weights \path{efficientnetb3_4class.keras}, \path{densenet121_4class.keras}, \path{cnn_4class.keras}.
    \item Run order: build the manifest, train all models, evaluate, optionally run the leakage probe, and then start \path{Frontend/app.py}. The portable bundle in \path{xray-classifier-portable/} already includes the three \texttt{*.keras} weight files, so the demo can be run without retraining on your own machine.
\end{itemize}
